# ログイン時の419画面・HTTP 500の修正

2026年10月22日。XAMPPのApache・PHP 8.2.12とChromiumで確認。

## 原因と変更

`/%ce%b2team/login.php`を開いたとき、セッションCookieのPathは`/%CE%B2team/`になっていた。ブラウザーのCookieのPath照合では大文字小文字が区別されるため、ログインPOSTへCookieが送られず、CSRFトークンが一致しなかった。

CookieのPathをREQUEST_URIから作り、既存のパーセント表記の大小文字を維持する。未エンコードの日本語等はエンコードし、既にエンコード済みの文字は二重にエンコードしない。クエリ文字列はPathの算出から除く。

CSRF不一致時は標準のHTTP 403を返す。この環境では以前の419応答が、画面本文には419と表示されながらブラウザーではHTTP 500として観測された。CSRF検証自体は維持し、不正な送信を受理する変更はしていない。

## 確認結果

| 確認 | 結果 |
|---|---|
| 修正前・小文字URLでブラウザーから送信 | 本文419、HTTP 500を再現 |
| 小文字・大文字・混在表記の3種類のURL | CookieのPathがアクセスURLに一致 |
| 3種類それぞれで正常なCSRF・不正なメールを送信 | HTTP 200で入力エラーを表示。期限切れ画面にならない |
| 3種類それぞれで不正なCSRFを送信 | HTTP 403で拒否 |
| 小文字・大文字URLで試験用講師のログイン | 初回パスワード変更画面へ到達 |
| 同じセッションでログアウト | ログイン画面へ戻る |
| 接続とテーブルを読み取りで確認 | 必要な7テーブルあり。試験用講師10人のパスワード照合も一致 |
| tests/unit.php | 既存31件と追加5件、計36件成功 |

追加ケースは小文字・混在パーセント表記、クエリ中のスラッシュ、空白のエンコード、文字としてのパーセントを確認する。生徒・講師情報、パスワード、DB定義は変更していない。

修正前から開いているログイン画面は、開き直してから入力する。Cookieを無効にしているブラウザーではセッションを引き継げないため、このサイトのCookieを許可する必要がある。
